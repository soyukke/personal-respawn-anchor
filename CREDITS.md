# Credits

Personal Respawn Anchor was inspired by the general idea of a placeable respawn
anchor, including the public `respawn-beacon` mod by micaalle:

https://mods.factorio.com/mod/respawn-beacon

This mod is an independent implementation:

- it does not copy `respawn-beacon` code
- it does not copy `respawn-beacon` artwork or thumbnail assets
- it does not use `force.set_spawn_position`
- it stores anchors per player and per surface, then teleports only the
  respawned player to their own anchor

The icon and thumbnail are original generated artwork prepared for this mod.
